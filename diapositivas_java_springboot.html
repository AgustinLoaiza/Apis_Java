1. Historia: de Java a Spring Boot

1991

El proyecto Oak nace en Sun Microsystems, pensado para dispositivos electrónicos.

1995

Java aparece públicamente con la idea “write once, run anywhere”.

2003

Spring Framework surge para simplificar el desarrollo empresarial en Java.

2014

Spring Boot aparece para crear aplicaciones Spring más rápido y con menos configuración.

Hoy

Java + Spring Boot se usa mucho en APIs REST, microservicios y sistemas empresariales.

Idea clave: Java es el lenguaje; Spring/Spring Boot ayudan a construir aplicaciones.2 / 8

Spring Framework vs Spring Boot

Spring Framework
  • Es el framework base del ecosistema Spring.
  • Proporciona inyección de dependencias, MVC, acceso a datos, seguridad, transacciones, etc.
  • Da mucho control, pero puede requerir más configuración manual.
Spring Boot
  • Se construye encima de Spring Framework.
  • Usa autoconfiguración y dependencias “starter”.
  • Permite crear aplicaciones ejecutables rápidamente, incluso con servidor embebido.

Spring Framework = base flexible · Spring Boot = Spring listo para arrancar

Diferencia principal: configuración manual vs configuración automática.3 / 8

2. Ventajas

⚡

Rápido desarrollo

Spring Initializr, starters y autoconfiguración reducen el tiempo de arranque del proyecto.

🧩

Ecosistema amplio

Integra web, datos, seguridad, pruebas, mensajería, microservicios y más.

🏢

Uso empresarial

Es fuerte para APIs REST, aplicaciones escalables y sistemas de backend mantenibles.

Java aporta estabilidad; Spring Boot aporta productividad.4 / 8

Desventajas

📚

Curva de aprendizaje

Hay muchos conceptos: beans, anotaciones, capas, JPA, seguridad y configuración.

🧠

“Magia” interna

La autoconfiguración ayuda, pero al principio puede ser difícil entender qué está pasando.

💾

Consumo de recursos

Comparado con tecnologías más livianas, puede usar más memoria y tardar más en iniciar.

No es malo: solo requiere comprender bien el framework.5 / 8

3. Características de Java

  • Orientado a objetos: organiza el código en clases y objetos.
  • Portátil: corre sobre la JVM en distintos sistemas operativos.
  • Robusto: manejo de excepciones, tipado fuerte y administración de memoria.
  • Multihilo: permite ejecutar varias tareas de forma concurrente.

Ejemplo simple

class Usuario { private String nombre; public Usuario(String nombre) { this.nombre = nombre; } }
Java es la base sobre la que corre Spring Boot.6 / 8

Características de Spring Boot

  • @SpringBootApplication: punto de entrada principal.
  • Auto-configuración: configura componentes según dependencias.
  • Starters: agrupan dependencias comunes.
  • Servidor embebido: Tomcat, Jetty o Undertow sin instalar aparte.
  • Actuator: métricas, salud y monitoreo de la aplicación.

Controlador REST

@RestController public class HolaController { @GetMapping("/hola") public String hola() { return "Hola Spring Boot"; } }
Con pocas líneas se puede exponer una API REST.7 / 8

Conclusión

Java ofrece una base sólida y Spring Boot permite construir aplicaciones modernas de backend de forma más rápida, ordenada y preparada para producción.

Mensaje para cerrar

Spring Boot no reemplaza a Spring Framework: lo simplifica y lo acelera para crear proyectos reales con menos configuración inicial.
